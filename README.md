An original procedural illustration of a luminous folded-paper phoenix unfolding a miniature universe. Its deterministic standard-library entrypoint delivers the artwork inside the competition sandbox.

## Run it

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The output is `out/entry.png`. Rebuilding the original artwork uses the build-time renderer and its documented dependencies; the submission runtime needs only Python's standard library.
